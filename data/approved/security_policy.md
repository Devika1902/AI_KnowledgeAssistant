# Example information security policy

This document is fictional demonstration content for evaluating the prototype. It is not an organisational policy.

## Incident reporting

Employees must report suspected security incidents to the Security Operations team within 24 hours of discovery. Reports should include the time observed, the affected system, and a short description. Reports must not include passwords.

## Account security

Passwords must be at least 14 characters long. Multi-factor authentication is required for remote access. Passwords must not be shared with colleagues or stored in plain text.
